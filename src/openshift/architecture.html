Numbered execution flow

1

Operator triggers patch

User enters CVE ID or picks from CVE tab → Start Patch Process. Console creates an in-progress run row immediately.

Console UI POST /api/start
2

Load CVE from Insights

Fetch CVE metadata and list of affected systems via Insights MCP (routed through Llama Stack /v1/responses).

vulnerability__get_cve insights-mcp
3

Score hosts & RAG analysis

Compute risk score per host (CVSS, age, blast radius). For hosts above threshold: search Milvus for patch history, then LLM summarizes operational context.

vector_stores/search /v1/responses Milvus
4

Generate Ansible playbook

Build remediation playbook YAML using Insights remediation tools and review-host UUIDs.

remediations__create_vuln_playbook
5

Publish playbook to GitHub

Push generated YAML to agentic-ai-patching repo. Small payloads via Llama Stack MCP; large playbooks (>8KB) use direct GitHub MCP.

PLAYBOOK_PUSH_METHOD=mcp|git GitHub
6

Sync AAP project

Trigger AAP project update so the controller pulls the latest playbook from Git.

AAP REST API
7

Create AAP templates

Create job template (playbook run) and workflow job template with an approval node before execution.

AAP REST API
8

Launch workflow job

Start workflow job from template. Workflow runs until it hits the approval gate (status remains running).

AAP
9

Operator approval

Console polls workflow_approvals and shows Approve / Deny in the Patch Runs table.

Console UI POST /api/approve AAP
10

Execute remediation job

After approval, workflow continues and launches the playbook job against target inventory. Console polls job status until complete.

AAP playbook job Status in UI
